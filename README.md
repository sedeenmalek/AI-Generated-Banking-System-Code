# AI-Generated Banking System Code

This repository contains the banking system source code generated by an LLM as part of our security comparison study.

## Overview
- **System:** Core banking operations (account creation, deposits, withdrawals, transfers).
- **Source:** Generated using AI.
- **Purpose:** Used as a test sample in our vulnerability detection pipeline (`AI-Generated-Code-Security-Evaluator`) to compare its security level against a human-written version.
